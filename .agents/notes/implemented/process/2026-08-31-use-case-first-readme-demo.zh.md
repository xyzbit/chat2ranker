# Agent Note: 以使用场景为先的 README 演示

Status: implemented

[English](2026-08-31-use-case-first-readme-demo.md) | 中文

## Problem

产品 README 在说明 Chat2Ranker 帮助用户做出哪些选择之前就进入评测流程。静态截图还要求读者自行还原对话、运行确认、结果对比和侧边工作区之间的关系。

## Decision

根 README 在安装说明之前给出四种具体用途：比较模型版本、比较 Harness、比较 Agent 配置和发现回归。每种用途都说明需要固定的变量以及可比较的指标。

一段贴合产品现有视觉的短片展示完整实验：从描述目标开始，经过数据与 Agent 准备、明确确认运行、结果对比，最后查看侧边工作区。README 嵌入高清封面并链接到 1080p MP4，同时移除重复表达相同流程的静态截图。

## Alternatives considered

**只保留功能说明。** 功能清单能够说明有哪些组件，但读者还需要自行把组件转换为实际评测决策。

**为每一步保留独立截图。** 静态图片可以分别更新，但会增加浏览长度并与动画重复。

**嵌入动态 GIF。** GitHub 可以稳定渲染，但 GIF 调色板转换和 README 缩放会让界面小字明显变糊；高清封面链接 MP4 能保留可读性。

## Consequences

读者可以在安装前判断产品是否适合自己的场景，也可以在不阅读架构文档的情况下理解完整交互。仓库增加两个生成后的媒体文件；产品流程发生实质变化时需要同步刷新，避免 README 展示过期界面。
