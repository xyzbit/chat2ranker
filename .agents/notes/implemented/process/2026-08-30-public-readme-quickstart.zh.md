# Agent Note: 公开 README 与一分钟上手

Status: implemented

[English](2026-08-30-public-readme-quickstart.md) | 中文

## Problem

根 README 在公开启动路径之前介绍了仓库所有权和开发架构，本地验收指南则把首次用户设置与贡献者依赖、进程拓扑和发布验证混在一起。新用户无法快速识别完成第一个实验的最短路径。

## Decision

中英文根 README 以已发布的 `npx` 命令、面向结果的一句话说明和真实产品截图开篇。它们概括评测行为并链接架构文档，不在启动前教授仓库内部结构。

独立的中英文 Quickstart 教程负责首次模型设置、第一个实验、结果查看、后台运行和隔离环境。`rank/docs/local-acceptance.md` 负责源码启动和贡献者验收。根文档不放 Star 历史趋势图；当前产品证据和启动路径优先于增长装饰。

## Alternatives considered

**保留一个综合指南。** 单文件可以少维护一组文档，但会继续混合用户与贡献者的阅读顺序，遮挡首次成功运行路径。

**在 README 中加入发布与 Star 历史面板。** Badge 可以紧凑展示发布状态，趋势图却会占据显著空间，并不能帮助用户启动或评测 Agent。

**只发布独立文档站首页。** 独立站点以后可以提供更丰富的导航，但从 GitHub 和 npm 进入的用户仍需要在仓库入口获得完整启动路径。

## Consequences

新用户可以在阅读架构或源码依赖前复制一条命令。维护者必须让两种语言的 Quickstart 和两张产品截图与可见的初始化、运行卡片及结果行为保持一致。贡献者验收保留完整细节，但不再承担公开首页职责。
