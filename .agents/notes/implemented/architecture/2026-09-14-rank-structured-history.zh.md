# Agent Note: 结构化会话历史

Status: implemented

[English](2026-09-14-rank-structured-history.md) | 中文

## 问题

将会话压成一条用户提示词会丢失角色和工具调用语义。若把这些历史导入为原生 Harness 执行，则会伪造轮次、工具活动和用量。不同适配器接受不同输入时，部署不能宣称它们具有相同的多轮行为。

## 决定

[Execution 输入](../../../../execution/backend/contract/messages.go) 在 `prompt` 与 `messages` 中只接受一种。结构化历史是一项通过 `structuredHistory` 公布的 Agent 能力；不支持的 Rank 续聊在 Response 接纳前拒绝，Execution 和运行时派发再次检查能力。DSH 和演示适配器支持此能力。可配置命令通过显式的 `{input}` JSON 文件参数声明支持。原生 Codex、Claude Code 和 Hermes 适配器在完成历史接入前仍只支持提示词。

[Rank](../../../../rank/backend/internal/app/serving.go) 从固定版本的会话中冻结有序的用户、助手和工具消息。助手调用携带原始 ID、名称与对象参数；工具结果保留匹配 ID。结果后的补充用户文本保留为独立用户消息。未完成调用要求连续提供结果，再接收其他消息。附件保留冻结引用及物化的输入文件；文本标记不代表原生多模态模型输入。

[DSH 历史运行器](../../../../apps/execution-runtime/README.md) 验证私有输入文件，将先前消息导入为 `history/message`，再用最后一条输入唤醒一个 Agent。助手历史使用插件来源。该事件提供模型上下文，不声称发生过原生轮次、模型调用、工具执行或 Token 用量。首次进入步骤的工具结果排在注入的启动上下文之前，保持调用与结果相邻。压缩从派生消息中统计工具块，包括导入消息和本轮工具输入。会话引用包含导入的用户与助手文本，排除工具输出及注入上下文。

`history/message` 是读取时必须识别的事件。旧 Harness 构建拒绝该未知事件；预发布会话格式仍为 `0`。Execution 协议版本保留 `2`，因为结构化请求省略 `prompt`，旧 Execution 验证器会拒绝它而不会压平处理。API、Worker 与运行时镜像必须一起部署；不支持的版本明确拒绝，不提供转换回退。

## 考虑过的替代方案

**将标注角色的 JSON 塞进一条提示词。** 容易传给所有 CLI，但不会形成供应商原生的助手或工具消息，也无法约束工具关联。

**根据外部消息伪造已完成的 Harness 轮次。** 将外部历史误记为本地执行，影响用量、生命周期不变量和恢复决策。

**恢复每个适配器的原生会话。** 需要适配器专属的持久状态、隔离及供应商重放规则。结构化历史无需宣称这种更强的恢复保证，也能独立发挥作用。

## 影响

真实构建后的 DSH CLI 冒烟测试向本地兼容 OpenAI 的 HTTP 服务发送三类输入：用户/助手/用户、调用方工具续聊，以及工具输出加额外用户输入。测试检查供应商角色、调用 ID、相邻关系和单次调用用量。[TypeScript/Python SDK 快照](../../../../examples/jsonrpc-agent/tests/history.snapshot.ts) 记录导入事件、模型可见会话及仅本次生成的回复。核心测试覆盖不可变重放、非法导入、轮次间不变量、引用投影及压缩配对。打包后的 Rank 试用验证续聊、取消与重启，以及不支持的适配器在接纳前拒绝。

通用输入不会恢复进程、工作区、供应商推理状态或任意原生 CLI 会话。外部函数选择仍使用 Rank 现有的可审阅函数输出格式；本次变更保留已完成的调用与结果历史，不向每个 Harness 新增原生外部工具声明。[平台实验](2026-09-14-rank-platform-lab.md)覆盖了经过集群的 DSH 续聊。整个运行时的 Sandbox 隔离仍见[生产提案](../../proposed/architecture/2026-09-14-rank-production-execution.md)。
