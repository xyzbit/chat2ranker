# Agent Note: Rank 工作区管理员访问

Status: implemented

[English](2026-09-15-rank-management-access.md) | 中文

## 问题

Rank 共享工作区包含 Agent 定义、数据集、模型连接管理和发布控制。只有网关密码时，私网 Rank 与 control-host 地址仍缺少保护，发布没有应用认证身份，中控服务的 HTTP 访问范围也不受限。

## 决策

每个工作区管理员通过网页登录或 HTTP Bearer/Basic 客户端 使用独立高熵令牌认证。带版本的管理员文件保存主体、令牌 SHA-256 摘要与可选过期时间。Rank 每次请求读取文件；原子替换支持新旧令牌重叠轮换和吊销。文件无效或不可用时，管理访问返回依赖错误，不保留过期授权。凭据与摘要不进入身份 API 响应、对话文本或执行快照。

管理员管理整个共享工作区及其对外服务租户。Agent、Dataset 和模型连接定义仍属于整个安装实例。对外 API 凭据保留已有的租户、端点与操作限制。管理员令牌不能调用公开 Responses API；对外 API Key 不能管理 Rank。这提供受控工作区访问，不提供团队隔离的 SaaS 数据归属。向团队用户开放前，需要为这些共享领域对象完整增加持久归属。

`rankd` 监听非回环地址时必须配置管理员文件。启用文件后，即使使用 SQLite 也必须显式配置内部密钥，防止已知开发中控令牌绕过管理员认证；仅回环地址的本地开发可省略。control-host 绑定非回环地址前检查 Rank 已开启管理认证，随后每次公开会话、消息和流请求都通过 Rank 授权。网关公开提供登录页面，并转发管理员认证及浏览器 Cookie；后端检查也保护直接私网访问。生产浏览器需要 TLS 网关，并在两个服务上配置公开来源。变更请求拒绝其他来源。

中控令牌是独立服务身份。明确的路由白名单覆盖实验/初始化读取、评测默认值、非秘密模型配置，以及已有内部命令/对话同步协议。它不能创建对外 API Key、读取其管理列表、删除连接或填写模型密钥。网关隐藏内部中控接口和运行时重载。直接发布与发布任务创建记录已认证主体，不信任调用方填写的操作者。

授权在请求准入时判断。吊销管理员或对外 Key 会阻止后续请求，不取消已接受工作，也不追溯终止已建立的流。Kubernetes Secret 投影到挂载文件后变更才生效；集群验证器等待实际观察到准入与吊销结果，不把 Secret 更新成功当成即时生效。

## 考虑过的替代方案

**只在 Nginx 认证。** 直接服务访问会保留另一套安全行为，发布身份仍依赖客户端填写。

**自建完整身份平台。** 基于随机管理员凭据的轻量浏览器会话支持普通网页登录，无需承担密码找回或用户注册。数据库会话无需新增身份服务即可在 API 替换后保留登录。需要时可接企业 SSO；本实现不宣称提供 SSO 或团队隔离。

**给中控服务管理员凭据。** 模型驱动工具会因此获得秘密管理权限。明确的服务白名单保留已有的秘密不进入聊天规则。

## 影响

[minikube 报告](../../../../rank/deploy/reports/2026-09-15-management-access.md)记录已安装镜像、观察到的授权结果和十项通过的完整平台检查。

[打包案例](../../../../rank/examples/access-control/README.md)验证实际 Rank/Execution 进程、管理员轮换、无效文件拒绝、可信发布身份，以及对外租户/端点/操作隔离。HTTP 测试覆盖服务权限、Basic 身份不匹配和跨来源变更。[平台验证器](../../../../rank/deploy/k8s/verify-platform.mjs)通过网关重复对外权限场景，替换投影管理员白名单，并在已有 DSH 对话与恢复场景前检查直接中控访问及服务限制。

管理员凭据发放与文件权限属于部署管理。完整审计日志、企业身份集成、团队归属、内部服务令牌轮换、工作负载身份和网络隔离仍是[生产方案](../../proposed/architecture/2026-09-14-rank-production-execution.md)中的独立工作。

网页登录使用固定有效期的不透明 HttpOnly Cookie、显式同源变更检查与服务端退出。Rank 对每次 Cookie 认证请求复核当前凭据文件。浏览器只在身份验证后挂载业务视图，会话过期返回登录并保留 URL。control-host 仅向身份验证接口转发 Cookie。有容量限制的数据库存储依照[滚动 API 决策](../bug-fix/2026-09-17-rank-api-rolling-drain.md)在进程间共享 Cookie 和凭据摘要，不持久化原始凭据。[打包案例](../../../../rank/examples/access-control/README.md)在不调用外部模型的情况下验证登录、Cookie 写入、退出及凭据吊销。
