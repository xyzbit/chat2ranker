# Agent Note：Agent 试用

Status: implemented

[English](2026-09-11-agent-playground.md) | 中文

## 问题

在 Rank 中控对话中选择 Agent 是配置评测，不是调用该 Agent。必须准备数据集或编写接入代码才能体验对话，会妨碍快速检查，也让回答者身份不清晰。

## 决策

统一对话侧栏通过明确的 Rank 与试用 Tab 切换。共享位置避免两个助手入口竞争，独立的会话状态保留回答者身份和工具权限。Agent 详情将不可变配置与独立保存的评测默认值分开：配置包含运行设置、直接展示的工具与 Skill、版本创建及独立对比页面的链接；评测包含 Agent 默认测试集与所选版本的记录。两个面板保持挂载，使未保存的评测选择在切换 Tab 后保留。评测跳转创建独立实验和绑定具体版本的待发送请求，避免修改用户已有实验。

Agent 会话面板管理独立于 Rank 中控的试用会话及历史。面板与 Agent 配置或部署路由并排，历史按 Agent 分组，在当前操作中呈现试用对象，无需独立导航页面。首次消息固定 Agent 版本，也可从部署别名解析版本。试用使用运营端身份复用 Response 的请求接纳、持久化、执行和恢复；可空的部署及凭据引用避免制造公开调用资源。Rank 中控产生持久化跳转入口，不冒充或静默调用被试用 Agent。[试用参考](../../../../rank/docs/agent-playground.md)统一说明 API 和交互语义。

## 考虑过的替代方案

**顶级导航中的独立试用页面。** 在配置与试用之间切换增加了导航步骤，却没有增加另一项任务，因此不采用。

**把中控会话切换为所选 Agent。** 实验状态、历史和工具属于 Rank，切换会让回答者身份混淆，因此不采用。

**为每次试用创建隐藏 Deployment 和 API Key。** 未发布测试会承担无关的路由及凭据生命周期，因此不采用。

**复制 Serving 执行逻辑。** 调用、续聊、取消和恢复容易与外部接入发生偏差，因此不采用。

## 影响

无需 Dataset 即可试用固定版本，也不必先发布。失败尝试保留审计，后续轮次只带入已完成上下文。试用流量不会触发生产 Webhook，公开调用 Key 无法访问。SQLite 迁移 20 保留已有引用并验证外键。免密钥的完整服务和 Worker 对话快照覆盖续聊、固定版本、重复发送、失败、取消、重启和中控跳转；浏览器验收覆盖桌面与手机导航及持久化。原生协议事件在展示给用户前完成转换。调用方业务工具和新的 Harness 交互审批不属于试用模块。
