# Agent Note: 对话配置表单

Status: implemented

[English](2026-09-13-conversation-configuration.md) | 中文

## Problem

只有通过管理导航才能操作的配置会打断 Rank 对话。让中控模型接收包含凭据的 API 响应，会将密钥持久化到会话并暴露给后续模型调用。

## Decision

Rank 工具直接处理非密钥的测试集版本、Agent 版本、模型信息、绑定、评测默认值、端点创建和发布门槛。持久化的 `a2ui/open_configuration` 事件为安全表单和设置确认提供有明确类型的配置操作。操作记录配置类型与资源引用，重新打开时读取当前状态，不授权或暗示保存。未知字段在存储命令与事件前被拒绝。

会话通过原生对话框复用平台表单。密钥创建和输入保留在浏览器内存及确定性的 API 调用中，关闭后丢弃明文。Webhook 配置在端点页和会话中共享同一组件。数值发布策略在直接 API 和对话命令中使用相同验证与事务方法。

视觉层级采用中性表面、克制的操作色、字号和留白。必要验证、运行限制不可变提示和密钥保留信息仍然可见，省略重复的页面说明。

手机端小助手位于顶部工具栏的历史和文档入口旁，避免覆盖表单操作。桌面端保留悬浮入口。

## Alternatives considered

**通过凭据修改工具返回 API 响应**会把 API Key 或签名密钥暴露在持久化且对模型可见的历史中。

**所有配置都跳转管理页面**会要求用户离开会话并重新寻找请求的上下文。

**另建一套会话表单**会重复验证，并让权限默认值和保存行为与管理页面发生偏差。

## Consequences

配置保持可从对话操作，敏感操作使用确定性表单，简单的非密钥修改直接执行。浏览器偏好和文件仍需浏览器参与。历史操作重新打开当前配置，而非可编辑的历史快照。无密钥 Control Host 对话快照覆盖工具执行与事件持久化；浏览器验收使用临时服务验证真实密钥、Webhook、策略修改及桌面与移动端表单行为。
