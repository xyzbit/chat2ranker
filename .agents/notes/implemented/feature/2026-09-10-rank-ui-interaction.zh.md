# Agent Note: Rank UI 交互

Status: implemented

中文 | [English](2026-09-10-rank-ui-interaction.md)

## 问题

密集控件、不一致的排版和常驻内部滚动条分散了对话内容的注意力。更新时自动滚动会打断阅读历史消息的用户。菜单和表单需要在窄工作区中保持可预测的键盘行为。

## 决策

共享中性背景、克制的强调色、控件尺寸和清晰的次要文字统一管理与对话页面。Rank、试用和最近会话区域隐藏滚动条，仅在有未显示内容的边缘渐隐。其他滚动区域在悬停或获得键盘焦点时显示细滑块，轨道透明且没有边框和箭头按钮。尺寸和内容观察器刷新渐隐提示；自动跟随取决于读者是否仍接近底部。强制颜色模式恢复滚动条并移除遮罩。

原生模态弹窗负责焦点约束和关闭。可搜索模型菜单使用原生浮层，避免被可滚动面板裁切，支持键盘选择选项，并先于外围检查器处理 Escape。单选字段遵循 [共用控件决策](2026-09-10-rank-shared-controls.md)。表单和文字保持实底；仅移动端固定导航使用半透明。

[流式交互与检查决策](2026-08-24-rank-streaming-control-and-inspector.md) 继续负责对话事件和工作区职责。[多 Agent 决策](2026-08-25-rank-multi-agent-comparison.md) 继续负责选择持久化和运行分组。

## 考虑过的替代方案

**始终滚到最新更新。** 执行进度到达时会打断历史消息阅读。仅在接近底部时跟随，可兼顾实时观察与历史检查。

**半透明表单和大范围阴影。** 这会降低文字对比度，给工作页面增加互相竞争的层次。轻微半透明仅用于覆盖滚动内容的导航。

**绝对定位模型菜单。** 检查器的滚动容器会裁切菜单。原生浮层保留表单关系，同时在容器上方渲染。

## 影响

导航语言切换采用现有图标库的翻译符号，并提供本地化的无障碍名称与提示。

普通颜色模式下隐藏滚动条会移除拖动入口；边缘渐隐、滚轮、触摸和键盘滚动保持可用。原生弹窗和浮层需要现代浏览器。浏览器回归检查运行于组装后的 Rank UI 并记录响应式截图；文字转录快照无法表达滚动位置、焦点或裁切。
