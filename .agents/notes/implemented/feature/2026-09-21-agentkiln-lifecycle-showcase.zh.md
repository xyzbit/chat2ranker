Status: implemented

[English](2026-09-21-agentkiln-lifecycle-showcase.md) | 中文

## 问题

以实验为中心的首页无法说明如何创建、试用、交付和接入 Agent。访问者需要先看到完整工作流，再了解其中的具体工具。

## 决策

[产品 README](../../../../README.md) 按创建、对话试用、测评对比、端点发布和接入的顺序介绍产品。无声 HyperFrames 视频和五张实际界面截图展示这条流程。简短中文字幕让视频无需音频也能理解；英文 README 描述相同能力。

截图保留真实 UI 状态。对比示例使用确定性 Demo Runner，并明确标注为示例数据。其中的通过率和成本用于说明界面，不作为模型质量证据。API 示例显示环境变量引用，不展示凭据。

## 考虑过的替代方案

**继续以实验演示作为主要介绍。** 它能解释评测，但会让创建和交付路径难以被发现。

**重建理想化产品界面。** 这类画面可能暗示应用没有提供的控件或没有完成的操作。真实截图使介绍对应已有行为。

## 影响

UI 变化可能让截图和视频过时；更新时需要重新采集、运行 HyperFrames 布局检查，并目视检查关键时刻和转场。文档检查验证链接与双语结构，不验证画面中的产品行为。原实验视频保留为历史素材。
