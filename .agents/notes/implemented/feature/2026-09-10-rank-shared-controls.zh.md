# Agent Note: Rank 共用控件

Status: implemented

中文 | [English](2026-09-10-rank-shared-controls.md)

## 问题

单独美化部署菜单后，设置、筛选器和表单仍使用不一致的原生菜单。重复焦点规则和页面选择器会让局部视觉修复影响其他控件。重复选项列表也可能在不同连接编辑器中出现偏差。

## 决策

`ManagementUI.jsx` 管理页面标题、错误提示、状态标签、空状态、分页和行内确认。页面直接引用这些展示组件。分页接收可用状态和回调，确认组件接收文案和操作；请求、游标历史及待执行操作仍由各页面管理。

`SelectField` 负责所有固定选项下拉框。其属性提供受控值、值变更回调、无障碍标签和选项。Radix 负责键盘导航和焦点管理。禁用的空值选项作为必填字段占位项；可选空值仍可选择。存在原生模态弹窗时，菜单挂载到最近的弹窗内，Escape 先关闭菜单再关闭父级。

`theme.css` 管理视觉变量，`controls.css` 管理控件与焦点样式，`ui-config.js` 管理共享菜单几何参数。页面负责布局位置和业务状态。语言选项属于 i18n，Provider 和协议选项属于模型连接代码。后端目录、凭据和各表单草稿不会成为 UI 常量。可编辑模型输入和可搜索模型发现保留各自交互。

此决策仅替代 [UI 交互决策](2026-09-10-rank-ui-interaction.md) 中的原生单选框选择；该记录继续负责滚动、模态行为和半透明设计。

## 考虑过的替代方案

**逐页独立美化下拉框。** 相同的键盘、禁用和焦点行为需要重复维护，局部修改也无法修复其他页面。

**只修改原生选择框触发器。** 浏览器管理的弹出菜单仍因平台而异，用户打开菜单时仍能看到差异。

**把所有值放进一个全局配置对象。** Provider 目录和表单草稿具有不同的归属及生命周期。把它们与视觉变量混合，会模糊哪些变更只影响展示、哪些会影响保存的实验。

## 影响

共用样式变更覆盖设置、初始化、Agent 表单、部署表单和筛选器。空值转换和弹窗菜单归属需要明确的浏览器回归覆盖。页面规则排除共用选择框时不增加优先级，使已有列表行样式保持原优先关系。组装后的桌面和移动端浏览器检查覆盖选择、禁用占位项、可重置筛选器、模型连接草稿、嵌套 Escape 行为和弹窗菜单位置。
