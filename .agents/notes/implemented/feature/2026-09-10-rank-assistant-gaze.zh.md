# Agent Note: Rank assistant gaze

Status: implemented

[English](2026-09-10-rank-assistant-gaze.md) | 中文

## Problem

Rank 助手需要易于识别、能响应交互的表情，同时避免分散阅读注意力或移动对话内容。

## Decision

头像采用纯色圆形与两只白色眼睛。轻微的定时左右张望赋予表情，附近的鼠标移动优先控制视线。动作限制在现有头像尺寸内。减少动态效果设置使头像保持静止，触摸输入不触发跟随。浏览器监听器和待执行动画帧由挂载的头像持有，卸载时释放。

## Alternatives considered

**整个头像移动。** 倾斜或弹跳整个头像会在长对话中持续吸引注意力。眼睛移动能够实现所需响应，同时减少视觉干扰。

**持续跟随鼠标。** 跟随页面任意位置的鼠标会使远处的对话头像对无关操作作出反应。局部响应半径限制了这种干扰。

## Consequences

表情仅作装饰，不表示执行状态，也不改变对话事件。浏览器验证覆盖闲置张望、远近鼠标、触摸输入、减少动态效果以及桌面和移动端渲染。文本对话快照无法呈现视线方向，因此浏览器冒烟检查记录完整对话页面的视觉快照。
