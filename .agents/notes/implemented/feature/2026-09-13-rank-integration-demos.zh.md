# Agent Note：Rank 接入案例

Status: implemented

[English](2026-09-13-rank-integration-demos.md) | 中文

## Problem

API 片段不能证明已发布 Agent 在应用中的效果。新闻 demo 可能把模型记忆误作实时数据，纯浏览器接入也可能暴露凭据。

## Decision

[Responses 案例](../../../../rank/examples/responses-client/README.md)通过官方 SDK 提供一次同步热点请求和流式聊天应用。新闻采集先于模型请求，保留时间与链接；来源为空或不可用时不调用模型。

仅监听本机的 demo 使用 HttpOnly 访客 Cookie，在内存中保存消息和最新已完成 Response ID。凭据只在服务端环境中。取消明确调用 Rank，失败或取消后需新建会话。浏览器 Markdown 由 Marked 解析、DOMPurify 净化。

独立 ZIP 通过明确的 Vite 导入白名单和 fflate 压缩库复用这些源码。`.env.example` 只包含端点和平台配置，密钥由用户在本地填写。两个包选择默认案例及不同端口，共享运行代码和验收。包内教程不依赖仓库相对路径，验证结果保留在解压目录中。按需加载避免首次打开应用就下载打包源码。

## Alternatives considered

**仅依靠模型生成今日新闻**不能证明时效。**Agent 外部工具往返**有价值，但不是这里演示的单次 Responses 创建。**浏览器 SDK 凭据**会暴露密钥。**生产会话基础设施**为本地教程增加无关的部署要求。

**要求克隆仓库**为 API 教程增加无关准备。**递归收集压缩文件**可能纳入本地凭据或运行文件，源码白名单固定包内内容。**分别复制实现**容易偏离，因此两个下载包复用经过验证的运行代码。

## Consequences

取消更新被并发的排队到运行状态变更拒绝时，会重新读取并重试。直接返回刚进入运行状态的 Response 会确认取消请求，却未停止执行。已有终态则优先生效，不被覆盖。确定性的竞争回归测试检查这两种结果，下载 Demo 的真实验收通过平台代理验证立即取消。

[调用反馈](../../../../rank/docs/response-feedback.md)将应用 Response ID 连接到排查详情和经过审核的数据集采集。操作者独立填写期望并明确脱敏独立文本；将实际输出当成正确答案会把原始问题带入评测。用例保留来源引用，追加创建不可变版本并拒绝过时版本及重复来源。独立用例执行无法复现原运行环境，因此完整会话、附件和工具自动重放留待后续支持。无需密钥的 Rank/Execution 应用级场景检查采集、评测和冻结 Run 数据；浏览器验收覆盖搜索、刷新、审核和准确的评测衔接。

案例是教学应用，不是公开多用户服务。会话在 24 小时后或重启时失效，Rank 记录继续保留。无密钥测试通过确定性 Responses 传输和对话快照覆盖已组装的 demo HTTP 服务与官方 SDK。真实验收覆盖实时来源、记忆、持久输出、版本固定、隔离和取消；缺少凭据时失败而非跳过。真实模型文案不作为确定性快照。
