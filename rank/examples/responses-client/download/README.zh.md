# 运行 Rank 接入案例

[English](README.md) | 中文

本教程通过下载包运行示例，无需克隆 Rank 仓库。每日热点先采集实时资料，再创建一次 Response；聊天助手采用流式输出，并从最新完成的 Response ID 续聊。两者均通过官方 OpenAI SDK 调用已发布端点，API Key 只留在本地 Node.js 服务端。

## 1. 准备

安装 Node.js 22.19 或更高版本，保持 `.env.example` 中地址对应的 Rank 服务运行。端点需要已发布的 Agent，且使用可用的真实模型。这两个文本案例无需本地工具或 Skills。在端点接入侧栏创建 API Key，授权该端点的发起、读取和取消操作。原值请保存在本地，Rank 无法再次恢复。

## 2. 启动

解压 ZIP，在 `rank-news` 或 `rank-chat` 文件夹中打开终端，运行：

```sh
npm ci
cp .env.example .env
```

Windows PowerShell 使用 `Copy-Item .env.example .env` 替代 `cp`。用编辑器打开 `.env`，在 `RANK_API_KEY` 填写 Rank 调用密钥，而非底层模型供应商密钥。`RANK_MODEL` 是端点名称。下载时已预填地址与名称，平台地址变化后可修改。不要将 `.env` 放进仓库或浏览器代码。然后运行：

```sh
npm start
```

打开终端打印的 URL。每日热点默认端口为 4181，聊天助手为 4182。如果端口占用，修改 `.env` 的 `DEMO_PORT`。每次修改配置后重启。页头文档链接指向 `RANK_PLATFORM_URL` 对应的平台，请求详情中的调用记录链接也使用该地址。

## 3. 试用效果

**每日热点：** 点击生成日报。应用获取 HN 最近 24 小时的提交，按社区积分选取最多十个标题，再只发起一次 Rank 请求，生成五条带编号来源的中文摘要。来源失败时不会调用模型。这是基于标题整理的社区热点，不是全网热搜或全文核查。`npm run news` 可在终端运行同一任务，不会创建每日定时任务。

**聊天助手：** 先发送“我叫小林，喜欢科技新闻，每天有 10 分钟”，再问“我叫什么，每天有多少时间？”预期看到流式正文，并保留前文事实。每个浏览器访客的 Response ID 保存在服务端。同一访客的多个标签共享会话，不同访客相互隔离。刷新保留当前进程的对话。停止会调用 Rank 取消接口，之后需要新建对话。重启 Demo 会清空会话，Rank 中的调用记录仍保留。

## 4. 验证

```sh
npm test
npm run verify:demos
```

第一条命令运行无需密钥的 HTTP 测试和对话快照。第二条针对配置的真实端点验证两个流程，共创建四次 Rank 请求，最后一次会取消；可能产生模型费用，并需要访问 HN。缺少配置或验证失败会以非零状态退出。验证结果不含密钥，写入当前目录下的 `output/integration-demos-live.json`。

## 排查参考

| 现象 | 操作 |
| --- | --- |
| 连接被拒绝 | 启动 Rank，检查 `RANK_BASE_URL`，修改后重启 Demo。 |
| 401 | 更换无效或已撤销的 Rank Key，不要使用模型供应商密钥。 |
| 403 / 404 | 检查端点名称及端点、操作权限，不可见资源可能返回 404。 |
| 409 | 发布端点；使用最新完成的 Response 续聊，同一会话只运行一轮。 |
| 429 | 检查端点限流、并发策略并等待，示例关闭 SDK 自动重试。 |
| HTTP 200，但结果失败 | 检查 `status` 或 SSE 终止事件，保留 Response ID 并打开调用记录。 |
| 流式连接中断 | 刷新查看已保存状态；断开连接不会取消 Rank 执行，不要直接重发。 |
| 来源失败 | 检查 `hn.algolia.com` 是否可达，此时尚无 Rank 请求或 Response ID。 |

请求已接收时，展开请求详情并进入调用记录，检查冻结的 Agent 版本、输入、输出与失败原因。无效密钥等接收前错误通常没有 Response ID，也不会产生调用记录；保留 HTTP 状态和错误码即可排查，不要分享密钥。流式请求只有收到 `response.completed` 才算成功，`response.failed`、`response.cancelled` 或没有完成事件都不是成功结果。

平台文档包含追加指令、外部函数、SSE 恢复和聊天接入说明。这些 Demo 是本地教学应用：会话在 24 小时或重启后失效，密钥留在服务端，服务只监听本机。生产使用需要认证、持久会话和访问控制。文本 Demo 不执行外部函数；函数调用与结果回传请参考外部工具文档。
