# 本地生产路径验收 — 2026-09-15

[English](2026-09-15-production-local.md) | 中文

共享模型账号限流及剩余本地恢复、扩缩容窗口已在远程 minikube 平台通过。本文覆盖本地实现验收；物理多机验证由运维后续完成。[机器可读证据](2026-09-15-production-local.json)保留精确镜像、样本、验证源码摘要和原始报告标识。

## 环境

平台与网关使用 `09a7dc4989fbd5c3` 镜像标签，Sandbox 镜像摘要为 `sha256:98ae4daa4d023f80ef7de0ef487209a47743976835ecae34b4284f51d35946a2`。PostgreSQL schema 7 和 Worker 协议 3 同步部署。拓扑为单节点 minikube、恢复后的两个 Worker Pod、外部 Docker OpenSandbox 服务、PostgreSQL/River 和 SeaweedFS S3。共享运行时资源池仍限制为 2 CPU、2 GiB；增加 Worker 副本不会创建另一台运行时主机。

## 结果

| 范围 | 观察结果 |
| --- | --- |
| 完整平台回归 | 部署镜像上的十项检查全部通过，覆盖管理鉴权/撤销、公共凭据、端点调用、试用、中控会话、S3 证据、请求预算和重启恢复。 |
| 共享额度 | 两个独立本地 Worker 进程在两个连接间共享 RPM/TPM。API 重启保留扣减，修改速率不清空用量；取消、幂等重提保持一次尝试，不支持的 Harness 被准入拒绝。 |
| 远程限流与扩容 | OpenSandbox 中真实 DSH 通过受限入口申请许可。七个额度阻塞任务在 25 秒 KEDA 采样期间不计入可执行需求，Worker 没有扩容；回调入口拒绝服务令牌及管理路径。 |
| DeepSeek 案例 | 实际近 24 小时 HN 标题生成带引用的中文摘要。两轮 SSE 聊天记住姓名、兴趣和十分钟时间。三个响应均完成，保存正数用量和 S3 产物，并完成 Sandbox 清理。 |
| 供应商预算 | 共四次真实请求，包含一次连接验证。配置输出上限不超过 512 token；三个案例响应实际输出为 219、47、13 token。转发账本在派发前持久记录总数，没有通过重试重置。 |
| 组合故障 | PostgreSQL 失联加真实 Worker SIGKILL 后收敛为未知结果，保持 attempt 1、一次外部效果，并确认运行时清理。幂等重提不再次执行。 |
| 对象/引用窗口 | S3 确认 PUT 成功后，暂扣返回 Worker 的确认，再杀死 Worker。已知回答与用量保留；对象没有数据库引用，产物 API 读取返回 404。已识别该对象，供运维按保留策略回收。 |
| 空库初始化 | 在新数据库上将打包的 Rank、Execution 迁移执行两次。两个 schema 拥有者正确，业务表保持空状态，River 和额度表存在；只删除此临时测试库。 |
| 运行账号权限 | 使用 TCP 鉴权的应用账号可执行所需 DML，不能执行 DDL、读取另一服务的受保护表或修改迁移元数据。 |
| 自动活跃排空 | KEDA/HPA 选择正在执行任务的拥有者。宽限期内结束则成功，到期则标记未知结果；两种情况均保持一次尝试/外部效果，Worker 正常退出、Sandbox 释放，新任务由存活 Worker 执行。 |

活跃排空实验显式将缩容稳定窗口设为零，并通过 Pod 删除优先级选择活跃拥有者。常规配置仍保留 45 秒窗口。此实验验证自动选择后的停止行为，不代表生产缩容时延 SLO。结束后移除临时扩缩容与故障代理，并恢复两个 Worker。

## 测量与限制

热点请求端到端耗时 14.622 秒，包含来源收集与远程运行时启动；两轮聊天合计 27.443 秒。这是三个串行案例响应，不是压测 p95 或吞吐保证。账本中四次供应商请求均低于 2.3 秒；调整容量策略前，值得进一步测量冷启动和平台开销。确定性负载观察见此前的[容量报告](2026-09-15-autoscaling.md)。

TPM 先保守估算输入，再用正数实际用量调整，不是精确供应商计费或费用上限。DSH 内等待仍占用已有槽位。工具原生流量及恶意插件绕过不属于此协作式控制。不声称已完成自动孤立对象回收、生产 TLS 部署、物理多机性能或平台高可用。

真实供应商转发器已移除，对应临时端点/连接保留为验收历史，不能作为持续可用的连接；平台正常系统模型仍使用确定性实验连接。凭据未进入报告。[生产参考](../k8s/production.zh.md)明确私网、TLS、身份、轮换、存储保留及后续运维检查。
