| 数据库消失，最终镜像 | PostgreSQL 断开已建立连接，0.003 秒返回 HTTP 500。验证器要求八秒内收到真实服务端错误，拒绝客户端超时或只有传输失败的结果；立即断开无需耗尽超时预算。 |
| 持久恢复与产物中断 | 数据库丢失和上传中断均保留第一次尝试、一次外部工具操作，且确认运行时清理。上传失败保留已知输出、用量和已确认产物。旧产物仍可读，恢复后新调用成功。 |
| 丢弃真实 PostgreSQL 鉴权后的流量 | Go 集成代理在鉴权后保持两端 socket 打开并丢弃流量，查询 I/O 在调用方看门狗到期前返回时限错误。连接池耗尽、慢查询和更早的调用方取消也通过。 |
| Rank 事务与凭据查询 | 写锁竞争及事务后段发起的查询使用原事务截止时间。API Key 查询被阻塞时返回 503；解锁后有效密钥恢复正常，无效密钥仍返回 401。 |
