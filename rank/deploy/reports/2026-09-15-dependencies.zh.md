# 依赖中断实验 — 2026-09-15

[English](2026-09-15-dependencies.md) | 中文

远程 minikube 平台通过两项依赖故障场景及随后的公开客户端回归。[机器可读证据](2026-09-15-dependencies.json)记录镜像标识、源码摘要、观察结果及上传字节计数。私有报告保留在 Git 外。

| 场景 | 观察结果 |
| --- | --- |
| 真实 DSH 工具调用期间移除 PostgreSQL | 数据库 Pod 已删除，鉴权执行读取触及客户端十秒超时。恢复后，原执行以明确的结果未知原因失败，attempt 为一；外部操作只发生一次，运行时删除已确认。 |
| 首个产物成功后中断 S3 请求体 | 代理中断十次重试上传，共接收 13,528 字节，仅转发 160 字节。模型、工具调用未重放。执行在第一次尝试失败，保留已知输出、用量及一个已确认的压缩会话产物；经产物 API 解码 base64 后，SHA-256 一致。 |
| 恢复 | 原有产物字节不变，新调用在第一次尝试完成。使用原请求键仍返回原失败执行。模型、代理 fixture 已删除，PostgreSQL 与对象 Service 选择器已恢复，两个 Worker 保持健康。 |
| 完整平台回归 | 最终镜像下的热点请求、两轮 SDK 聊天、直接试用、持久中控会话、S3 读取、SSE 重放、Rank/中控替换及排队请求恢复全部通过。 |

产物中断场景暴露了已观察结果丢失及二进制预览被 UTF-8 转换破坏的问题。Executor 按进度持久化已知结果和已确认引用，预览响应明确声明编码。此前验证器运行还发现本地产物测试缺少根目录、容量快照落后，以及代理清理超时与退出宽限相等的问题。最终运行使用修正后的 fixture、当前快照和有时限的清理。

这是单台笔记本上的确定性实验，不是存储故障切换、模型质量测试或生产时延目标。数据库失联可能阻止内存结果持久化，此时明确报告未知结果并禁止重放。不可用读取的实测是客户端超时，不证明服务端能在限定时间内返回 503；请求及数据库截止时间仍需作为生产加固项处理。对象提交成功、数据库引用尚未记录的窗口仍可能产生无引用对象。复现方法见[实验教程](../k8s/README.md#dependency-interruption-experiment)，[决策记录](../../../.agents/notes/implemented/architecture/2026-09-15-execution-failure-evidence.md)定义结果和产物语义。
