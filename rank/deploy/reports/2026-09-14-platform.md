## Environment and coverage

A dedicated single-node `rank-dev` minikube cluster runs PostgreSQL, SeaweedFS, Execution API, two DSH workers, Rank API, the persistent control host, Nginx and a deterministic model service. The node container has 4 CPUs and 4 GiB; its Kubernetes allocatable report reflects the larger Docker VM and is not a usable capacity guarantee. The [Execution report](2026-09-14-execution.md) records dependency images and fixture scaling evidence. The platform uses Linux arm64, Node 24.21.0, Go 1.26.0 and River OSS 0.47.0. Worker limits are 1 CPU/768 MiB, one online and one evaluation slot, 60-second execution timeout and 75-second owner rescue threshold.

The model service implements real HTTP/streaming protocols but returns deterministic fixture text. No external model key is required. The daily-news scenario does not fetch live news. The fixture endpoint uses an explicit manual release override, so this run does not establish evaluation/regression quality or release-policy coverage. Control-session retention is checked through resumption metadata, not a claim that `/session` returns a transcript.

Browser verification found and fixed a PostgreSQL boolean-argument encoding error in trial history. Regression tests reproduced the failure before passing against SQLite and real PostgreSQL; the packaged trial snapshot replays on both databases. The packaged endpoint/release snapshot passes on PostgreSQL. Screenshot digests are recorded in the machine-readable evidence; originals remain in local acceptance artifacts.

## Limits and next acceptance

The lab verifies process distribution on one laptop, not physical-host scaling, production throughput or high availability. It uses a trusted shared database role and management Basic credential; it does not establish production tenancy or complete Harness isolation. Chrome at 1440×1000 verifies Agent details, two trial turns and reload recovery, navigation to an existing endpoint, the integration drawer, settings and documentation. This run does not cover every browser interaction or mobile viewport. The [production design](../../../.agents/notes/proposed/architecture/2026-09-14-rank-production-execution.md) retains separate work for isolated runtimes, actionable scaling metrics, bounded autoscaling and limited real-provider/cross-host validation.
