# 在对话中配置 Rank

[English](conversation-configuration.md) | 中文

Rank 对话支持与平台表单相同的配置。普通配置值可以直接写在消息中；密钥、权限确认和浏览器文件通过会话中打开的明确表单操作。

| 配置 | 对话行为 |
| --- | --- |
| Agent 运行方式、模型、指令、工具和 Skills | 创建 Agent 或不可变新版本。 |
| 测试集用例、结构、描述和评分标准 | 创建测试集或新版本；省略的字段保留基础版本的值。替换用例可以修改或删除已有用例。 |
| 默认开发集和回归集 | 独立于 Agent 版本更新 Agent 级默认值。 |
| 评测 Agent 和重复次数 | 按指定版本和次数准备确认，启动仍需明确确认。 |
| 模型连接信息和价格 | 直接更新非密钥字段；凭据与验证打开对应连接表单。 |
| 对话和评审模型 | 绑定已验证连接及模型，或打开系统模型表单。 |
| 端点运行限制 | 创建时指定速率、并发和超时，之后保持不可变。 |
| 发布门槛 | 更新指定数值，保留省略值；不会发布或改变正在执行的检查。 |
| API Key | 打开表单创建、确认权限或吊销。 |
| 本地连接 | 打开发现与导入，不替换系统模型绑定。 |
| Webhook | 打开配置创建、启用或停用订阅；签名密钥保留在表单中。 |
| 语言和小助手 | 打开浏览器偏好设置，包括本地精灵文件导入。 |
| 接入 | 打开端点的 Key 选择和可执行示例。 |

配置操作是持久化会话事件。点击后重新读取当前设置，打开操作不代表已保存。关闭密钥表单会丢弃明文。配置事件只存储配置类型与资源引用，不保存 API Key、签名密钥或复制的可执行命令。用户不需要在对话中输入内部 ID 或 JSON。

## 示例

- “用已验证的 DeepSeek 连接创建一个客服 Agent。”
- “修改这个测试集的评分标准，保留已有用例。”
- “创建端点 support-test，每分钟 30 次请求、同时处理 2 个请求。”
- “把 support-test 的最低通过率设为 95%。”
- “创建一个 API Key”会打开安全表单，不在聊天中返回密钥。
- “配置 support-test 的 Webhook”会打开对应端点的配置。

模型凭据由 Execution Service 凭据存储保管。调用密钥只存储哈希，明文展示一次。API 详情见[接入鉴权](serving-api.zh.md)。
