# Product

## Register

product

## Users

Agent builders and operators configure, evaluate, publish, and inspect versioned Agents from a local development console.

## Product Purpose

Rank combines conversation-driven configuration and evaluation with stable Deployment endpoints for external callers.

## Brand Personality

Calm, concise, approachable. Preserve the existing light interface and restrained violet actions.

## Anti-references

Avoid duplicate workspace navigation, permanent second conversation lists, unsolicited progress panels, and fabricated performance metrics.

## Design Principles

Conversation is the primary entry. Common actions use durable A2UI cards. Detailed management remains available in dedicated pages. A small companion opens the same conversation from those pages. Navigation appears above recent conversations in one sidebar.

## Accessibility & Inclusion

Support Chinese and English, keyboard operation, visible focus, reduced motion, and responsive desktop and mobile layouts. Keep secrets in secure forms.
